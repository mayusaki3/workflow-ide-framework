# Workflow IDE Framework “Kairi” （ワークフローIDEフレームワーク「海狸」）

Workflow IDE Framework “Kairi” は、Rust で IDE（統合開発環境）型アプリケーションを構築するための、アプリケーション組み込み型フレームワークライブラリです。

“Kairi” の語源は、日本語でビーバーを意味する「海狸（かいり）」です。さまざまな材料を組み合わせて環境を築くビーバーのように、IDE型アプリケーションに必要な共通機能を組み合わせ、アプリケーション開発の土台となることを目指しています。

## リリース状況

v0.1.0 を開発中です。
