# 仕様目次

Kairiの機能仕様はConsumer Applicationが利用範囲を段階的に広げられる順序で構成する。
章番号はConsumer Applicationに対して利用可能な仕様範囲を示す単位として使用する。

## 第1章 全体構造 — 整理済み

- [アーキテクチャー](01_アーキテクチャー.md)
- Kairi / Consumer Application責務境界
- Application / Project / Workspace / Panelの関係
- Public API / Event Referenceの位置付け

## 第2章 Application / Project — 実装済み・検証前

- [Application / Project仕様](02_Application_Project.md)
- [Application-level Public I/F設計](02_Application_Public_IF_設計.md)
- [Application / Project API Reference](Reference/01_Application_Project_API.md)
- Kairi導入、起動・終了、metadata、Menu / Command、Status、About / Version
- Project New / Open / Save / Save As / Close、互換性、Dirty、Recovery

自動テストとSample Applicationによる最終検証完了後、「第2章利用可能」とする。

## 第3章 Workspace — 未実装

Default Workspace、Workspace登録・切替、Layout、Application設定、Project / User Preferencesへの永続化を対象とする。正式仕様は未作成。

## 第4章 Panel — 再整理中

Panel登録・lifecycle、Panel Instance、Workspace配置、Dock / Floating / Visibility、Standard / Application Panelを対象とする。既存実装・旧仕様を現行章構成へ再整理する。

## 第5章 Resource — 再整理中

Application / Project / External Resource、Resource Registry、Selector、Import / Export、監視、操作、Recoveryを対象とする。既存実装・旧仕様を現行章構成へ再整理する。

## 第6章 Common Services — 再整理中

Notification、Logging、Localization、Theme / Appearance等を対象とする。既存実装・旧仕様を現行章構成へ再整理する。
