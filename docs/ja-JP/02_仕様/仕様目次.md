## Public API / Event Reference

Public API と Event の詳細定義は機能仕様とは別系列の Reference とする。
各機能章では、その章の実装に必要な API / Event の名前、利用箇所、シーケンスを示し、型・引数・戻り値・payload・厳密な発火条件等は Reference へリンクする。

- Application API Reference
- Project API Reference
- Workspace API Reference
- Panel API Reference
- Resource API Reference
- Command API Reference
- Event Reference

Reference は独立した「機能解禁章」として数えない。利用可能とされた機能仕様章から参照される Reference は、その機能仕様とともに利用可能とする。
