# Kairi 全体概要

## 1. 目的

Workflow IDE Framework “Kairi” は、Rust で IDE 型アプリケーションを構築するためのアプリケーション組み込み型フレームワークです。

Project、Workspace、Panel、Resource、Menu / Command、Status、Logging、Localization、Theme 等、IDE型アプリケーションに共通する基盤をKairiが担当し、Consumer Applicationが固有機能の実装へ集中できることを目的としています。

特定のWorkflow、Runtime、AI、シミュレーション等をKairi自身の必須用途にはしません。これらはKairi上に構築されるConsumer Applicationの利用例または拡張対象として扱います。

## 2. 対象利用者

主な利用者は、IDE型UIとProject管理を持つRust Applicationを開発するConsumer Application開発者です。

利用例には、Runtime / Simulation IDE、AI / Asset Studio、Workflow Editor、GPU Viewportを持つ開発・検証Application等があります。

## 3. Framework / Consumer Application の責務

KairiはIDE共通機能とdomain非依存のmodel / action / Public APIを所有します。

Consumer Applicationはdomain model、domain validation、Application固有Project data、Resourceの意味、Runtime等の用途固有処理を所有します。

ConsumerがKairi内部実装をforkまたは直接変更することを利用条件としません。

## 4. 全体構造

Kairiの機能は、Consumer Applicationから見て次の順序で整理します。

1. Application / Project
2. Workspace
3. Panel
4. Resource
5. Common Services

ApplicationはKairiの最上位利用単位であり、ProjectはApplication levelで管理するデータです。

WorkspaceはPanelの配置とLayoutを管理し、Panel instance自体はApplicationが所有します。

## 5. 対象OS

対象OSはWindows / Linux / macOSです。

- Windows: 実機検証対象
- Linux: VMを含め検証し、実機必須項目は未検証として明示可能
- macOS: 環境を用意できない項目は未検証として明示可能

未検証は非対応を意味しません。検証状態は検証資料で区別します。
