# Kairi 全体概要

## 1. 目的

Workflow IDE Framework “Kairi” は、Rust で IDE 型アプリケーションを構築するためのアプリケーション組み込み型フレームワークです。

プロジェクト、ワークスペース、パネル、リソース、メニュー、コマンド、ステータス、ログ、多言語対応、テーマなど、IDE型アプリケーションに共通する基盤をKairiが担当し、利用アプリケーションが固有機能の実装へ集中できることを目的としています。

特定のワークフロー、ランタイム、AI、シミュレーションなどをKairi自身の必須用途にはしません。これらはKairi上に構築される利用アプリケーションの利用例または拡張対象として扱います。

## 2. 対象利用者

主な利用者は、IDE型のユーザーインターフェースとプロジェクト管理を持つRustアプリケーションの開発者です。

利用例には、ランタイムやシミュレーションを扱うIDE、AIやアセットを扱う制作ツール、ワークフローエディター、GPUを利用する表示領域を持つ開発・検証アプリケーションなどがあります。

## 3. Kairiと利用アプリケーションの責務

Kairiは、IDE型アプリケーションに共通する機能と、特定用途に依存しない基盤を提供します。

利用アプリケーションは、用途固有のデータ、検証処理、プロジェクト固有データ、リソースの意味、ランタイムなどの用途固有処理を担当します。

利用アプリケーションがKairiの内部実装を変更することを利用条件とはしません。

## 4. 全体構造

Kairiでは、利用アプリケーションから次の機能を使用できます。

1. アプリケーション / プロジェクト
2. ワークスペース
3. パネル
4. リソース
5. 共通サービス

アプリケーションはKairiの最上位利用単位であり、プロジェクトはアプリケーションレベルで管理するデータです。

ワークスペースはパネルの配置とレイアウトを管理し、パネル自体はアプリケーションが所有します。

## 5. 対象OS

Windows / Linux / macOS での動作を想定しています。
