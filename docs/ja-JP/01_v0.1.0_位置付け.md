# v0.1.0 の位置付け

v0.1.0は、Kairiを利用アプリケーションから使用できるフレームワークとして公開する最初のバージョンです。

すべてのIDE機能を完成させることではなく、IDE型アプリケーションを構築するための基本機能と、利用アプリケーションから使用するための公開インターフェースを成立させることを目的とします。

## 1. 対象範囲

v0.1.0では、次の機能群を対象とします。

- アプリケーションとプロジェクト
- ワークスペース
- パネル
- リソース
- メニューとコマンド
- ステータス
- 通知
- ログ
- 多言語対応
- テーマとフォント
- プロジェクトの保存と復元
- リソースの参照、管理、監視、復旧
- 利用アプリケーション向けの公開インターフェース
- 利用例となるSample Application

各機能の詳細な要件、仕様および実装状態は、それぞれの要件・仕様文書で定義します。

## 2. 公開に必要な状態

v0.1.0の公開時には、次の状態を満たすものとします。

- v0.1.0の対象機能について、利用アプリケーションから使用するための公開インターフェースが定義されていること
- Kairiと利用アプリケーションの責務境界が定義されていること
- プロジェクトとリソースの所有範囲および永続化の境界が定義されていること
- ワークスペースとパネルの基本的な配置・保存が成立していること
- 利用アプリケーションがKairi内部実装の変更を前提とせずに基本的なIDE型アプリケーションを構成できること
- Sample Applicationが公開インターフェースを利用して構成されていること
- 公開するドキュメントと実装の内容が一致していること

## 3. 対象外

次の機能はv0.1.0の必須対象には含めません。

- 完全なプラグインローダーおよび動的プラグインAPI
- リモートランタイム
- AIランタイムおよびデバッガー
- プロジェクトのパッケージ化およびエクスポート
- リソースのコピー、切り取り、貼り付け
- 高度なドッキングおよびフローティングウィンドウ管理
- 利用アプリケーション固有のエディターやランタイム
- UIの細かな視覚調整
- Validation Captureの完全実装

v0.1.0の対象外である機能についても、将来の拡張を不必要に妨げる公開インターフェースにはしません。

## 4. OS別対応状況

対象OSごとの対応・検証状況は、[OS別対応状況](./02_OS別対応状況.md)で管理します。

v0.1.0の公開条件として、すべての対象OSで全機能の検証が完了していることは要求しません。未検証項目は未検証であることを明示します。
