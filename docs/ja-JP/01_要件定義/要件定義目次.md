## 機能レベル別の要件構成

Kairi の機能要件は、Consumer Application が上位レベルから順に実装・利用範囲を拡張できるよう、次の単位で整理する。

1. **Application / Project**
   - Kairi の組み込み
   - Application lifecycle
   - Application metadata / version
   - Menu / Command
   - Status
   - About / version information
   - Project lifecycle / persistence
2. **Workspace**
   - Workspace registration / selection
   - Layout
   - Application からの設定
   - Project / User Preferences への永続化
3. **Panel**
   - Panel registration / lifecycle
   - Workspace への配置
   - Dock / Floating / Visibility
   - Standard Panel / Application Panel
4. **Resource**
5. **Common Services**
   - Notification
   - Logging
   - Localization
   - Theme / Appearance
   - その他の共通サービス

機能仕様の章番号は Consumer Application に対する利用可能範囲の識別にも使用する。
例えば「Kairi 機能仕様 第1章～第3章を利用可能」と指定した場合、その章から参照される Public API / Event Reference も利用対象に含む。
