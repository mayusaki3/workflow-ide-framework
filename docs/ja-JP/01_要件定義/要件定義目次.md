Kairiの組み込み、Application lifecycle、metadata / version、Menu / Command、Status、About、Project lifecycle / persistenceを対象とする。

## Resource — 再整理中

Application / Project / External Resource、Registry、Selector、Import / Export、監視、操作、Recoveryを対象とする。

## Common Services — 再整理中

Notification、Logging、Localization、Theme / Appearance等を対象とする。
