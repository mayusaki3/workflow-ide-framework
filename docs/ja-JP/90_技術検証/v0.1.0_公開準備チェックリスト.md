# v0.1.0 公開準備チェックリスト

## 1. 目的

Workflow IDE Framework v0.1.0 を公開可能な状態へ整えるためのGateを定義する。
細かなUI調整ではなく、Frameworkとしての機能成立、Consumer Applicationとの契約、再現可能な検証、公開文書の整合性を優先する。

## 2. Release Gate

- [ ] Application / Framework責務境界が仕様化されている
- [ ] Panel登録とPanel Instance識別が仕様化されている
- [ ] Menu / Command登録境界が仕様化されている
- [ ] Project Open / Save / Save As境界が仕様化されている
- [ ] Application project dataの保存・互換性・recovery境界が仕様化されている

- [ ] Property adapter / Flow validator / Controller action handlerが仕様化されている

## 3. 公開判定

v0.1.0では、全OS・全機能が○であることを公開条件とはしない。
未検証は？として明示し、既知の✕は制限事項として公開する。

ただし、Project formatやApplication APIなど公開後の互換性へ直接影響する境界に未整理の矛盾がある場合はRelease Gate未達とする。

## 4. 後続版へ送る項目

- UIの細かなサイズ・比率・配置調整
- Notificationの視覚的な細部調整
- 高度なDock/window management
- Project package/export
- Resource duplicate/copy/cut/paste
- 完全なPlugin Loader / dynamic Plugin API
- v0.1.0で必要性が確認できなかった利便機能
