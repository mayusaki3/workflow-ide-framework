# WV-11-04 Browser Surface 入力イベント転送検証

## 目的

Dock Panel 内へ Texture として表示した CEF OSR Browser Surface に対し、egui 側で取得した入力イベントを Browser へ転送できることを確認する。

WV-11-03 で成立した Browser Surface の表示経路を前提とし、本検証では入力経路のみを対象とする。

## 前提

- WV-11-03 により Browser Surface を Dock Panel 内へ表示できている。
- Browser Surface の OSR 描画領域と Dock Panel の表示領域を対応付けられる。
- Browser 用の独立 Native Window は使用しない。
- 正式 Surface API は本検証では定義しない。
- IME 固有処理、Drag and Drop、Touch、Pen は本検証の対象外とする。
- 範囲選択、Copy / Paste / Cut 等の Text Editing は WV-11-04-01 で別途検証する。
- IME 固有処理は WV-11-04-02 で別途検証する。

## 検証順序

1. Dock 座標から Browser OSR 座標への変換
2. Pointer 移動転送
3. Pointer Button 転送
4. Wheel 転送
5. Keyboard 転送
6. Text 入力転送

## INPUT-IT-SPEC-001 Pointer 座標変換
<!-- hldocs:sec_id=sec_v4c8n2q7m1px -->

### 概要

Dock Panel 内で取得した Pointer 座標を Browser OSR の論理表示座標へ変換できることを確認する。

### 前提条件

- Dock Panel 内の Browser Surface 表示矩形を取得できる。
- Browser OSR の論理表示サイズを取得できる。

### 検証内容

- Browser Surface 表示矩形内の Pointer 座標を Browser OSR 座標へ変換する。
- 表示矩形と OSR サイズが異なる場合も、それぞれの幅と高さに基づいて座標を対応付ける。

### 期待結果

- 表示矩形の左上が Browser OSR の左上へ対応する。
- 表示矩形の右下が Browser OSR の右下へ対応する。
- 表示矩形内の中間座標が同じ相対位置へ対応する。

### 参照仕様

- doc-20260524-009601Z-R8M7#sec_v4c8n2q7m1px

## INPUT-IT-SPEC-002 Pointer 移動転送
<!-- hldocs:sec_id=sec_k7w3f9r2d6ta -->

### 概要

Dock Panel 内の Pointer 移動を CEF OSR Browser へ転送できることを確認する。

### 前提条件

- INPUT-IT-SPEC-001 の座標変換が成立している。

### 検証内容

- Browser Surface 上の Pointer 移動を CEF Browser へ通知する。
- Browser 側で hover に応じて表示が変化する要素を使用する。

### 期待結果

- Pointer 位置に対応する Browser 要素へ hover 状態が反映される。
- Browser Surface 外の Pointer 移動を Browser 内の通常移動として扱わない。

### 参照仕様

- doc-20260524-009601Z-R8M7#sec_k7w3f9r2d6ta

## INPUT-IT-SPEC-003 Pointer Button 転送
<!-- hldocs:sec_id=sec_p2m8x5c1q7vz -->

### 概要

Dock Panel 内の Pointer Button 押下および解放を CEF OSR Browser へ転送できることを確認する。

### 前提条件

- Pointer 移動転送が成立している。

### 検証内容

- Browser Surface 上で Pointer Button を押下および解放する。
- Browser 側の clickable 要素で入力結果を表示する。

### 期待結果

- 対象要素の click 動作が発生する。
- 押下と解放が Browser へ正常に伝達される。

### 参照仕様

- doc-20260524-009601Z-R8M7#sec_p2m8x5c1q7vz

## INPUT-IT-SPEC-004 Wheel 転送
<!-- hldocs:sec_id=sec_a6t1n9w4k3rb -->

### 概要

Browser Surface 上の Wheel 入力を CEF OSR Browser へ転送できることを確認する。

### 前提条件

- Pointer 座標を Browser OSR 座標へ変換できる。

### 検証内容

- スクロール可能な Browser ページ上で Wheel 入力を発生させる。

### 期待結果

- Browser ページのスクロール位置が Wheel 入力に応じて変化する。

### 参照仕様

- doc-20260524-009601Z-R8M7#sec_a6t1n9w4k3rb

## INPUT-IT-SPEC-005 Keyboard 転送
<!-- hldocs:sec_id=sec_r5q9d2m8v1kc -->

### 概要

Browser Surface が入力対象である間、Keyboard 押下および解放を CEF OSR Browser へ転送できることを確認する。

### 前提条件

- Browser Surface を入力対象として識別できる。

### 検証内容

- Browser 側で Keyboard Event を表示する要素へキー入力を行う。

### 期待結果

- Browser 側で対象キーの押下および解放を識別できる。

### 参照仕様

- doc-20260524-009601Z-R8M7#sec_r5q9d2m8v1kc

## INPUT-IT-SPEC-006 Text 入力転送
<!-- hldocs:sec_id=sec_c3x7p1t9m5wf -->

### 概要

Browser Surface が入力対象である間、文字入力を Browser の編集可能要素へ反映できることを確認する。

### 前提条件

- Browser Surface 内の編集可能要素へ Pointer Button 入力でフォーカスできる。

### 検証内容

- Browser 側のテキスト入力要素へ文字列を入力する。

### 期待結果

- 入力した文字列が Browser の編集可能要素へ反映される。

### 参照仕様

- doc-20260524-009601Z-R8M7#sec_c3x7p1t9m5wf
