# OS別対応状況

KairiはWindows / Linux / macOSでの動作を想定しています。

OS別の機能検証結果は、対象OSを縦軸、検証項目を横軸とする検証表で管理します。CIによる自動検証とGUI・実機検証は区別します。

| Linux | ○ | ○ | ○ |

根拠: [develop / GitHub Actions run 38662259423](https://github.com/mayusaki3/workflow-ide-framework/actions/runs/38662259423)（コミット `6f94376c`、2026-10-15確認）。各OSの `cargo build --lib`、`cargo build --example step1_minimal`、`cargo test --all-targets --all-features` が成功。別ジョブの `cargo fmt --all -- --check` および `cargo clippy --all-targets --all-features -- -D warnings` も成功。

これらはCIのビルド・非対話テスト成功だけでは検証済みとしません。GUI操作の証跡（OS、実行環境、テスト対象、結果）を得た段階で項目ごとに更新します。

表記:

- ○: 該当項目の検証に成功（検証方法・環境は表と根拠に従う）
- ✕: 非対応または検証失敗
- ？: 未検証

LinuxはVMで検証可能な項目を検証し、実環境が必要な項目は未検証として扱います。

macOSは検証環境を用意できない項目を未検証として扱います。

未検証は非対応を意味しません。機能別検証の進行に合わせて、この表を詳細化します。
