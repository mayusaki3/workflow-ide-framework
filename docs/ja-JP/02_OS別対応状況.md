# OS別対応状況

KairiはWindows / Linux / macOSでの動作を想定しています。

OS別の機能検証結果は、機能を縦軸、対象OSを横軸とする検証表で管理します。

| 機能 | Windows | Linux | macOS |
|---|:---:|:---:|:---:|
| v0.1.0対象機能 | ？ | ？ | ？ |

表記:

- ○: 検証済み
- ✕: 非対応または検証失敗
- ？: 未検証

LinuxはVMで検証可能な項目を検証し、実環境が必要な項目は未検証として扱います。

macOSは検証環境を用意できない項目を未検証として扱います。

未検証は非対応を意味しません。機能別検証の進行に合わせて、この表を詳細化します。
