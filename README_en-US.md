# Workflow IDE Framework “Kairi”

Workflow IDE Framework “Kairi” is an embeddable Rust framework library for building IDE (Integrated Development Environment) style applications.

The name “Kairi” comes from the Japanese word “海狸（かいり）”, meaning beaver. Like a beaver that gathers and combines various materials to build its environment, Kairi aims to combine common capabilities required by IDE-style applications and provide a foundation for application development.
